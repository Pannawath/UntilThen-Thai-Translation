GUIDE - คู่มือการติดตั้ง

ขั้นตอนการลงม็อดภาษาไทยสำหรับ Until Then บนระบบ Steam (PC) อย่างละเอียด

01
DOWNLOAD FILE

ดาวน์โหลดและแตกไฟล์ม็อด

กดปุ่ม DOWNLOAD ที่หน้าหลักเพื่อรับไฟล์ zip ม็อดภาษาไทย จากนั้นทำการแตกไฟล์ (Extract Here) เพื่อรับโฟลเดอร์สำหรับติดตั้ง

UntilThen_ThaiMod.exe ~21 MB
02
STEAM DIRECTORY

ค้นหาโฟลเดอร์เกมในระบบ Steam

เปิดโปรแกรม Steam ➔ คลิกขวาที่เกม Until Then ➔ เลือก Manage (จัดการ) ➔ Browse local files (เปิดดูไฟล์ภายในเครื่อง) หรือคัดลอกที่อยู่ด้านล่างนี้:

Windows Steam Local Directory
C:\Program Files (x86)\Steam\steamapps\common\Until Then\

INSTALL & LAUNCH

DOCUMENTATION & TROUBLESHOOTING

[วิธีแก้ปัญหาที่พบบ่อย] Until Then - ม็อดภาษาไทย

ห้องนี้รวบรวมวิธีแก้ปัญหา ข้อสงสัย และบั๊กต่างๆ ที่พบบ่อยจากการใช้งานม็อดแปลไทย หากพบปัญหาในการเล่นหรือการติดตั้ง สามารถค้นหาวิธีแก้ไขตามหัวข้อด้านล่างนี้ได้ทันทีครับ

รองรับม็อดเวอร์ชัน v1.5.4 Hotfix (ล่าสุด)
หมวดที่ 1

ปัญหาการติดตั้งและตัวรันม็อด

Q1 ดับเบิ้ลคลิกเปิดตัวติดตั้ง .exe แล้วหน้าต่างปิดตัวเองทันที หรือไม่แสดงหน้าต่างขึ้นมา

สาเหตุ
  • เครื่องยังไม่ได้ติดตั้ง .NET Desktop Runtime เวอร์ชัน 9.0 (มักพบบน Windows รุ่นเก่าหรือเครื่องที่ลงวินโดวส์ใหม่)
  • โดนระบบความปลอดภัยของ Windows (Smart App Control) หรือโปรแกรม Anti-virus ปิดกั้นการทำงาน
วิธีแก้
  1. ดาวน์โหลดและติดตั้ง Microsoft .NET 9.0 Desktop Runtime (x64) ได้ฟรีจากเว็บไซต์ทางการของ Microsoft: dotnet.microsoft.com/download/dotnet/9.0
  2. หากมีหน้าต่างสีฟ้า Windows protected your PC ให้คลิก "More info" แล้วเลือก "Run anyway" หรือใช้ตัวติดตั้งเวอร์ชัน Lite ที่มีขนาดกะทัดรัดและโหลดเร็วกว่า
  3. หรือใช้คำสั่ง PowerShell ปลดล็อกทันที (ไม่ต้องปิด Antivirus):
    Windows PowerShell — Unblock-File
    powershell -ExecutionPolicy Bypass -Command "Get-ChildItem -Recurse | Unblock-File"

Q2 ตัวติดตั้งแจ้งเตือน Error Code: -2147450730 หรือ -1073740286 ขณะกำลังแพ็กไฟล์

สาเหตุ

โปรแกรมแพ็กไฟล์เกม (GodotPCKExplorer) ขาดคอมโพเนนต์ .NET 9.0 หรือไฟล์คอมโพเนนต์ .NET ในเครื่องเสียหาย

วิธีแก้
  • ในตัวติดตั้งเวอร์ชัน v1.5.4 ระบบมีปุ่มช่วยดาวน์โหลดและซ่อมแซม .NET ให้อัตโนมัติ ให้กด "ตกลง" เพื่อเริ่มการซ่อมแซม
  • หากยังไม่ผ่าน ให้ติดตั้ง .NET 9.0 Desktop Runtime แบบ Manual ตามลิงก์ในข้อ Q1 แล้วรีสตาร์ตเครื่องหนึ่งครั้ง

Q3 ตัวเกมบน Steam มีการอัปเดตแพตช์ใหม่ หรือเผลอกด "ตรวจสอบความสมบูรณ์ของไฟล์เกม" แล้วภาษาไทยหาย

สาเหตุ

ทาง Steam จะดาวน์โหลดไฟล์ UntilThen.pck ดั้งเดิมจากเซิร์ฟเวอร์มาเขียนทับไฟล์ม็อด

วิธีแก้

เปิดโปรแกรมตัวติดตั้งม็อด UntilThen_ThaiMod.exe แล้วกดปุ่ม "INSTALL MOD" ใหม่อีกครั้งได้ทันที ไม่ต้องโหลดไฟล์เกมใหม่

Q4 เล่นบนเครื่อง Steam Deck, Linux หรือ macOS ต้องติดตั้งอย่างไร?

วิธีแก้บน Steam Deck (Desktop Mode):
  1. เปิดโฟลเดอร์เกม Until Then ผ่าน Steam ➔ Manage ➔ Browse local files
  2. ดาวน์โหลดไฟล์ UntilThen_ThaiMod_Story.zip หรือนำไฟล์ UntilThen.pck ที่แพ็กภาษาไทยเสร็จแล้วจาก PC มาวางทับไฟล์เดิมในเครื่อง Steam Deck
  3. หรือใช้ Proton Tricks เพื่อรันตัวติดตั้ง UntilThen_ThaiMod.exe บน Steam Deck ได้โดยตรง
หมวดที่ 2

ปัญหากราฟิก ภาพแตก และฟอนต์

Q7 ภาพในฉาก 3D แตกเป็นลายตารางสีรุ้ง (Rainbow Static Noise) หรือภาพค้างระหว่างเปลี่ยนฉาก

สาเหตุ

บั๊กไดรเวอร์การ์ดจอ (โดยเฉพาะ Nvidia ซีรีส์ GTX 10xx / VRAM 4GB) เมื่อเปิดเอฟเฟกต์สะท้อนแสง VoxelGI สองชั้นพร้อมกัน

วิธีแก้
  • ม็อดเวอร์ชัน v1.5.4 มีระบบดักปิดการสะท้อนแสงซ้อนอัตโนมัติ ไม่ทำให้ภาพแตกหรือค้างอีกต่อไป
  • ผู้เล่นสามารถเข้าไปปรับตั้งค่ากราฟิกในการตั้งค่าได้อิสระเต็มที่ หากการ์ดจอมี VRAM น้อย แนะนำปรับ Bokeh Depth of Field และ Ambient Occlusion ลงมาที่ระดับ Medium หรือ High เพื่อความลื่นไหล

Q8 ตัวหนังสือในก้อนความคิด (Thought Bubble) หรือกล่องคำพูดเปลี่ยนเป็นฟอนต์อื่น สระลอย หรือเป็นสี่เหลี่ยม

สาเหตุ

ไฟล์ฟอนต์ของระบบความคิดไม่สมบูรณ์ หรือตัวเกมไม่โหลดแม็ปปิ้งฟอนต์

วิธีแก้

ใช้ม็อดเวอร์ชัน v1.5.4 ตัวเต็มทางการ ซึ่งกู้คืนไฟล์แม็ปปิ้งฟอนต์ Prompt แท้ (DiarioDeAndy) เข้าสู่ระบบเรียบร้อยแล้ว ติดตั้งใหม่ผ่านตัวติดตั้งแล้วเข้าเกม ตัวหนังสือจะกลับมาคมชัดสวยงาม 100%

Q9 ข้อความบทสนทนาล้นขอบจอ หรือกล่องคำพูดตกขอบ

สาเหตุ

ตัวเกมใช้มุมกล้อง 3D ที่ตัวละครยืนชิดขอบจอซ้ายหรือขวาเกินไป ทำให้กล่องข้อความเดิมไม่ปรับตามมุมกล้อง

วิธีแก้

ทีมงานได้ทำการปรับแบ่งบรรทัดด้วย ThaiWordBreaker Engine และปรับระยะความกว้างในม็อดเวอร์ชัน v1.5.4 ครบทุกฉากแล้ว หากยังพบประโยคใดที่ตกขอบ สามารถแคปภาพหน้าจอพร้อมชื่อฉากส่งมาแจ้งใน Discord ห้องแจ้งปัญหาได้เลยครับ

หมวดที่ 3

ปัญหาขณะเล่นเนื้อเรื่องและ DLC (Gameplay & DLC)

Q10 เล่นเนื้อเรื่อง DLC บทที่ 2 แล้วคลิกเมาส์บนหน้าจอมือถือหรือเมนูไม่ได้

สาเหตุ

เป็นข้อจำกัดจากตัวเกมต้นฉบับของผู้พัฒนา (Polychroma Games) ที่ไม่ได้เขียนระบบคลิกเมาส์ในหน้าจอดังกล่าวสำหรับ DLC บทที่ 2

วิธีแก้

ให้ใช้ "ปุ่มลูกศรบนคีย์บอร์ด (Arrow Keys)" หรือปุ่มลูกศรบนจอยเกม (D-pad) ในการเลื่อนเลือกเมนู และกด Enter หรือ Spacebar เพื่อยืนยัน (เนื้อเรื่องหลักและ DLC บทที่ 1 ใช้เมาส์ได้ปกติ)

Q11 เปิดแอปหาคู่ Matchy ในบทที่ 2 ฉากที่ 1 แล้วเกมเด้งหลุดทันที

สาเหตุ

โครงสร้างไฟล์ฐานข้อมูลแอปไม่ตรงกับเอนจินของตัวเกม

วิธีแก้

อัปเดตม็อดเป็นเวอร์ชัน v1.5.4 ขึ้นไป ปัญหานี้ได้รับการแก้ไขโครงสร้าง JSON ครบ 100% และแปลข้อมูลโปรไฟล์ตัวละครครบทั้ง 12 คนแล้ว สามารถเปิดแอปเล่นมินิเกมได้ปกติ

Q12 เกมจอดำ ค้าง หรือไม่เล่นบทสนทนาต่อ (เช่น ฉากเปียโน, บทที่ 4 ฉากซื้อเสื้อ, ลูปต่างๆ)

สาเหตุ

เกิดจากอักขระช่องว่างพิเศษ (NBSP) ในไฟล์แปลเวอร์ชันเก่าที่ทำให้เอนจิน Ink ประมวลผลค้างและไม่ปล่อย Event Trigger ข้ามฉาก

วิธีแก้
  • อัปเดตม็อดเป็นเวอร์ชัน v1.5.4 ซึ่งทีมงานได้ทำความสะอาดและตรวจสอบอักขระ NBSP ทั่วทั้งโปรเจกต์ 100% แล้ว อาการค้างจะหายเป็นปกติ
  • วิธีแก้ปัญหาชั่วคราว (ไม่ต้องลงม็อดใหม่): กด ESC เข้าไปที่ "การตั้งค่า" (Settings) ในเกม แล้วสลับเปลี่ยนภาษาเป็น English เฉพาะฉากนี้ก่อน เมื่อเล่นผ่านฉากนั้นจนเกมขึ้น Auto-Save ค่อยสลับภาษากลับมาเป็น ไทย เพื่อเล่นต่อตามเดิม
