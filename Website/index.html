INSTALLATION GUIDE กำลังโหลดเวอร์ชัน

ติดตั้งม็อดภาษาไทย
แล้วเลือกภาษาในเกม

คู่มือนี้อธิบายวิธีติดตั้งม็อดภาษาไทยสำหรับ Until Then เวอร์ชัน Steam บน Windows ตั้งแต่ดาวน์โหลดตัวติดตั้ง ไปจนถึงเลือกภาษาไทยในเกม

ดาวน์โหลดแอป เลือกไฟล์เกม INSTALL เลือกภาษาไทย
01
DOWNLOAD

ดาวน์โหลดแอปติดตั้ง

กดปุ่มด้านล่างเพื่อไปยังหน้า DOWNLOAD แล้วดาวน์โหลดแอปติดตั้งเวอร์ชันล่าสุด เมื่อดาวน์โหลดเสร็จ ให้ปิดเกม Until Then ก่อนเปิดแอป

02
GAME FILE

ตรวจตำแหน่งไฟล์เกม

ตัวติดตั้งจะค้นหาไฟล์เกมจาก Steam ให้อัตโนมัติ ตรวจสอบว่าพบไฟล์ UntilThen.pck ในตำแหน่งที่ถูกต้อง หากไม่พบ ให้กด BROWSE แล้วเลือกไฟล์นี้จากโฟลเดอร์ติดตั้งเกม

1 ตรวจสอบไฟล์เกม หากตัวติดตั้งหาไม่พบ ให้กด BROWSE
THAI TRANSLATION MODUNTIL THEN
กำลังค้นหาโฟลเดอร์เกม Until Then...
Version กำลังโหลดเวอร์ชัน

ตัวอย่างการใช้งาน: เลือก BROWSE, INSTALL หรือ UNINSTALL เพื่อดูขั้นตอน

ภาพนี้ใช้ประกอบคำอธิบายเท่านั้น การเลือกไฟล์และติดตั้งม็อดจริงต้องทำผ่านแอปติดตั้ง

หากไม่ทราบตำแหน่งไฟล์เกม ให้เปิด Steam คลิกขวาที่ Until Then → Manage → Browse local files แล้วเลือกไฟล์ UntilThen.pck

03
INSTALL

ติดตั้งม็อด

กด INSTALL แล้วรอจนตัวติดตั้งแจ้งว่าดำเนินการสำเร็จ ระหว่างนี้อย่าปิดโปรแกรมหรือเปิดเกม เมื่อติดตั้งครั้งแรก ตัวติดตั้งจะสำรองไฟล์เกมเดิมไว้เป็น UntilThen_Backup.pck สำหรับใช้คืนไฟล์เดิมในภายหลัง

กด INSTALL ในภาพจำลองด้านบนเพื่อดูคำอธิบาย จากนั้นทำขั้นตอนจริงในแอปติดตั้ง

04
IN GAME

เปิดเกมแล้วเลือกภาษาไทย

เปิดเกมผ่าน Steam แล้วเลือก SETTINGS จากเมนูหลัก ไปที่แท็บ GAME จากนั้นเลือก ภาษาไทย ในช่อง Language แล้วกด BACK เพื่อกลับสู่เกม

05
OPTIONAL

ถอนการติดตั้งม็อด

ปิดเกมแล้วเปิดแอปติดตั้ง ตรวจสอบว่าเลือกไฟล์ UntilThen.pck ของเกมที่ติดตั้งม็อดไว้ จากนั้นกด UNINSTALL แอปจะใช้ไฟล์สำรอง UntilThen_Backup.pck เพื่อคืนไฟล์เกมเดิม

อย่าลบหรือย้ายไฟล์สำรองจนกว่าจะถอนม็อดสำเร็จ หากไม่มีไฟล์นี้ จะไม่สามารถใช้ UNINSTALL เพื่อคืนไฟล์เกมเดิมได้

DOCUMENTATION & TROUBLESHOOTING

วิธีแก้ปัญหาที่พบบ่อยของม็อดภาษาไทย Until Then

หน้านี้รวบรวมวิธีแก้ปัญหาที่พบบ่อยจากการติดตั้งและเล่นม็อดภาษาไทย เลือกหัวข้อที่ตรงกับอาการเพื่อดูสาเหตุและวิธีแก้ หากยังแก้ไม่ได้ สามารถติดต่อทีมงานได้จากช่องทางท้ายหน้า

คู่มือการติดตั้งอ้างอิงแอปติดตั้งสำหรับ Windows ปัญหากราฟิกและเนื้อเรื่องอาจขึ้นอยู่กับเวอร์ชันของเกมและม็อด
วิธีแก้บั๊กเบื้องต้น

หากยังเข้าเกมได้ ให้ไปที่ SETTINGS → GAME → Language แล้วเลือก English เพื่อผ่านจุดที่มีปัญหาชั่วคราว หากเข้าเกมไม่ได้หรือยังพบอาการเดิม ให้ปิดเกม เปิดแอปติดตั้ง แล้วเลือก UNINSTALL เพื่อคืนไฟล์เกมเดิม

หมวดที่ 1

การติดตั้งและเปิดตัวติดตั้ง

Q1 เปิดแอปติดตั้งแล้วไม่แสดงหน้าต่าง หรือปิดตัวลงทันที

วิธีตรวจสอบ
  1. ดาวน์โหลดแอปติดตั้งใหม่จาก แล้วลองเปิดอีกครั้ง
  2. หาก Windows แสดงคำเตือน ให้ตรวจสอบชื่อไฟล์และแหล่งดาวน์โหลดว่าเป็นไฟล์จากหน้า Releases ก่อนดำเนินการต่อ หากข้อความระบุว่า Smart App Control บล็อกแอป ดูวิธีจัดการได้ที่ Q5: Smart App Control บล็อกตัวติดตั้ง
  3. หากยังเปิดไม่ได้ ให้บันทึกภาพข้อความแจ้งเตือน แล้วส่งให้ทีมงานผ่านช่องทางติดต่อท้ายหน้า

Q2 เกมแจ้งว่าไม่พบ UntilThen.pck หรือตัวติดตั้งหาไฟล์เกมไม่เจอ

วิธีแก้
  1. ปิดเกมและตัวติดตั้ง จากนั้นเปิดโฟลเดอร์เกมใน Steam โดยคลิกขวาที่ Until Then → Manage → Browse local files
  2. หากไม่พบ UntilThen.pck แต่พบ UntilThen_Backup.pck ให้เปลี่ยนชื่อไฟล์สำรองโดยลบเฉพาะ _Backup ออก ให้ชื่อไฟล์เป็น UntilThen.pck (อย่าลบนามสกุล .pck) แล้วลองเปิดเกม
  3. หากพบไฟล์ UntilThen.pck อยู่แล้ว อย่าเปลี่ยนชื่อไฟล์สำรองทับ ให้เปิดตัวติดตั้ง กด BROWSE แล้วเลือกไฟล์ UntilThen.pck ที่พบ
  4. หากไม่พบทั้งสองไฟล์ ให้ใช้คำสั่ง Verify integrity of game files ใน Steam เพื่อซ่อมแซมไฟล์เกม แล้วเปิดตัวติดตั้งอีกครั้ง

Q3 หลัง Steam อัปเดตหรือซ่อมแซมเกม ภาษาไทยหายไป

สาเหตุ

การอัปเดตหรือซ่อมแซมผ่าน Steam อาจแทนที่ไฟล์ UntilThen.pck ที่ม็อดแก้ไขไว้

วิธีแก้

อย่ากด INSTALL ซ้ำทันที เพราะไฟล์สำรอง UntilThen_Backup.pck อาจเป็นไฟล์จากเกมเวอร์ชันเก่า ให้ทำตามลำดับนี้: ปิดเกม → กด UNINSTALL เพื่อคืนไฟล์เดิม → ใช้ Verify integrity of game files ใน Steam เพื่อรับไฟล์เกมเวอร์ชันล่าสุด → ตรวจสอบว่าม็อดรองรับเกมเวอร์ชันนั้นแล้วจึงติดตั้งใหม่ หากพบข้อผิดพลาดระหว่างขั้นตอน ให้บันทึกข้อความแจ้งเตือนและติดต่อทีมงาน

Q4 สามารถติดตั้งบน Steam Deck, Linux หรือ macOS ได้หรือไม่?

ขอบเขตคู่มือ

คู่มือนี้ครอบคลุมแอปติดตั้งสำหรับ Windows เท่านั้น หากใช้ระบบปฏิบัติการอื่น โปรดตรวจสอบหน้า Releases ว่ามีแอปติดตั้งและคู่มือสำหรับระบบนั้นหรือไม่ก่อนเริ่มติดตั้ง

Q5 วิธีปิด Smart App Control เมื่อบล็อกแอปติดตั้ง

ตรวจสอบก่อน

ตรวจสอบว่าแอปติดตั้งดาวน์โหลดจากหน้า DOWNLOAD ของเว็บไซต์หรือหน้า Releases ทางการ และชื่อไฟล์ตรงกับที่ระบุไว้ หากหน้าต่างแจ้งว่า Windows protected your PC ให้เลือก More info ตรวจสอบชื่อแอปและผู้เผยแพร่ แล้วเลือก Run anyway ได้เฉพาะเมื่อมั่นใจว่าเป็นไฟล์จากแหล่งทางการ

ปิด Smart App Control
  1. เปิด Windows Security จากเมนู Start
  2. เลือก App & browser control → Smart App Control settings
  3. เลือก Off แล้วยืนยันข้อความแจ้งเตือนของ Windows
  4. ลองเปิดตัวติดตั้งอีกครั้ง และเปิด Smart App Control กลับหลังใช้งาน หากอุปกรณ์แสดงตัวเลือกให้เปิดอีกครั้ง

คำเตือน: การปิด Smart App Control มีผลกับแอปในเครื่อง ไม่ได้ยกเว้นเฉพาะตัวติดตั้งนี้ และลดการป้องกันจากแอปที่ไม่น่าเชื่อถือ ควรปิดเฉพาะเมื่อยืนยันแหล่งที่มาของไฟล์แล้วเท่านั้น หากไม่พบเมนูหรือเปิดกลับไม่ได้ อย่าปิดระบบป้องกันอื่นเพิ่ม ให้ติดต่อทีมงานหรือผู้ดูแลอุปกรณ์

หมวดที่ 2

กราฟิกและฟอนต์

Q7 ภาพฉาก 3D เป็นลายสีรุ้ง (Rainbow Static Noise) หรือค้างระหว่างเปลี่ยนฉาก

สาเหตุ

อาจเกิดจากไดรเวอร์การ์ดจอ โดยเฉพาะการ์ด Nvidia ซีรีส์ GTX 10xx ที่มี VRAM 4GB เมื่อเกมเปิดเอฟเฟกต์สะท้อนแสง VoxelGI ซ้อนกัน

วิธีแก้
  • ม็อดเวอร์ชัน v1.5.4 ปิดการสะท้อนแสงที่ซ้อนกันโดยอัตโนมัติ เพื่อช่วยป้องกันภาพผิดปกติหรือเกมค้าง
  • สามารถปรับกราฟิกในเกมได้ตามต้องการ หากการ์ดจอมี VRAM จำกัด แนะนำให้ลด Bokeh Depth of Field และ Ambient Occlusion เป็นระดับ Medium หรือ High เพื่อให้เกมทำงานได้ลื่นขึ้น

Q8 ข้อความในก้อนความคิด (Thought Bubble) หรือกล่องคำพูดใช้ฟอนต์ผิด สระลอย หรือแสดงเป็นสี่เหลี่ยม

สาเหตุ

ไฟล์ฟอนต์ของระบบความคิดอาจไม่สมบูรณ์ หรือตัวเกมอาจโหลดการจับคู่ฟอนต์ไม่สำเร็จ

วิธีแก้

ติดตั้งม็อดตัวเต็มเวอร์ชัน v1.5.4 หรือใหม่กว่า ซึ่งมีไฟล์จับคู่ฟอนต์ Prompt ต้นฉบับ (DiarioDeAndy) รวมอยู่แล้ว หากติดตั้งเวอร์ชันนี้อยู่แต่ยังพบปัญหา ให้ถอนการติดตั้งแล้วติดตั้งม็อดใหม่อีกครั้ง

Q9 ข้อความบทสนทนาหรือกล่องคำพูดล้นออกนอกจอ

สาเหตุ

บางฉากจัดวางตัวละครไว้ชิดขอบจอ ทำให้กล่องข้อความอาจแสดงไม่พอดีกับพื้นที่บนหน้าจอ

วิธีแก้

ม็อดเวอร์ชัน v1.5.4 ปรับการตัดคำด้วย ThaiWordBreaker Engine และแก้ความกว้างของกล่องข้อความแล้ว หากยังพบข้อความล้นจอ โปรดแนบภาพหน้าจอพร้อมระบุชื่อฉาก แล้วแจ้งทีมงานใน Discord

หมวดที่ 3

เนื้อเรื่องและ DLC

Q10 ใน DLC บทที่ 2 คลิกหน้าจอมือถือหรือเมนูด้วยเมาส์ไม่ได้

สาเหตุ

เป็นข้อจำกัดของตัวเกมต้นฉบับ โดยหน้าจอดังกล่าวใน DLC บทที่ 2 ไม่รองรับการคลิกด้วยเมาส์

วิธีแก้

ใช้ปุ่มลูกศรบนคีย์บอร์ด (Arrow Keys) หรือปุ่มทิศทางบนจอย (D-pad) เพื่อเลื่อนเมนู แล้วกด Enter หรือ Spacebar เพื่อยืนยัน เนื้อเรื่องหลักและ DLC บทที่ 1 ยังคงใช้เมาส์ได้ตามปกติ

Q11 เปิดแอป Matchy ในบทที่ 2 ฉากที่ 1 แล้วเกมปิดตัวลง

สาเหตุ

โครงสร้างข้อมูลของแอปไม่ตรงกับรูปแบบที่เอนจินเกมต้องการ

วิธีแก้

อัปเดตม็อดเป็นเวอร์ชัน v1.5.4 ขึ้นไป ซึ่งแก้ไขโครงสร้าง JSON และแปลข้อมูลโปรไฟล์ตัวละครทั้ง 12 คนแล้ว จากนั้นจึงลองเปิดแอป Matchy อีกครั้ง

Q12 เกมจอดำ ค้าง หรือบทสนทนาไม่ดำเนินต่อ (เช่น ฉากเปียโน ฉากซื้อเสื้อในบทที่ 4 หรือฉากวนซ้ำ)

สาเหตุ

วิธีแก้
